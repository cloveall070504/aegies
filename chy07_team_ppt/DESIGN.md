# DESIGN.md — chy07 团队分工与技术架构 PPT（科技蓝）

## 1. 画布与母版（默认 1280×720，A/B/C 三区）

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px | 主标题 34px bold；深色背景上用浅色文字 |
| **B · 内容区** | 120–660px | 540px | 正文、卡片、图表；禁止挤占 A/C |
| **C · 页脚条** | 660–720px | 60px | 左：项目名「chy07 团队分工」+ L3 角标；右：页码 `NN / 14`，14px 灰字 |

页面 padding：上下 20px、左右 64px。封面 / 章节过渡 / 结束页采用自定义版式（可省 C 区）。

## 2. 颜色系统（科技蓝 · 深色科技底）

| 角色 | HEX | 用途 |
| :--- | :--- | :--- |
| 背景主色 | `#0F172A` | 深蓝黑底，全篇统一背景 |
| 主色 | `#3B82F6` | 科技蓝，标题、主色块、渐变起色 |
| 辅色 | `#06B6D4` | 青色，卡片描边、第二系列、分隔 |
| 强调色 | `#8B5CF6` | 紫，仅用于焦点：巨型数字、核心标注 |
| 文本主色 | `#E2E8F0` | 浅灰白正文 |
| 中性灰 | `#64748B` | 页脚、次要文字、边框 |

**色彩面积分配**：主色 ≤ 60%（背景/大色块/标题栏）；辅色 ≤ 30%（卡片/图表系列）；强调色 ≤ 10%（焦点元素，Hero 页可到 15–20%）。
**色彩节奏**：Hero 页（01/06/14）强调色 15–20%；Supporting 页强调色 ≤ 5%、辅色 ≤ 20%；禁止全篇比例雷同，至少 2 页色彩比例显著不同。

**渐变方案**：
- 标题栏/卡片头：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)`
- Hero 背景：`linear-gradient(135deg, #0F172A 0%, #1E3A8A 55%, #06B6D4 130%)`（深蓝→蓝→青晕染）
- 半透明：卡片 `background: rgba(59,130,246,0.08)`；浮起 `boxShadow: '0 4px 20px rgba(0,0,0,0.35)'`

## 3. 字体系统

| 层级 | 字号(px) | 字重 | 字体 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 72 | bold | 微软雅黑 + letterSpacing 2px | 仅封面 |
| 章节大字 | 64 | bold | 微软雅黑 | 过渡/结束页 |
| 巨型锚点数字 | 96 | bold | Consolas / JetBrains Mono | 核心数据、5 人角色锚点 |
| 页面主标题 | 34 | bold | 微软雅黑 | A 区 |
| 卡片小标题 | 26 | 600 | 微软雅黑 | 卡片头 |
| 正文 | 22 | regular | 微软雅黑 | 段落 |
| 引文/注释 | 18 | italic | 微软雅黑 | 卡片尾部 |
| 脚注/页码 | 14 | regular | 微软雅黑 | C 区 |

**规则**：标题与正文同为微软雅黑，但巨型数字/锚点改用 Consolas 等宽字体制造尺度跳跃；禁止全篇系统默认无衬线无变化。

## 4. 信息密度门禁

- 常规内容页留白 ≤ 35%；封面/过渡/结束页不受限。
- 内容页最少元素：标题 + 正文 + 主视觉（≥30% B 区）。
- 卡片填充率 ≥ 85%：高 ≥ 380px 卡片正文 ≥ 100 字；尾部引文条 `marginTop: 'auto'` 钉底。
- 焦点留白：每个锚点元素周围留 ≥ 40px 呼吸空间。

## 5. 配图系统

| 等级 | 用途 | 接入 |
| :--- | :--- | :--- |
| L1 主视觉 | 封面背景、模块概念图、依赖架构图、集成架构图 | `ImageGen` 生成科技蓝风格插画/3D，存 `assets/`，逐张 Read 核对 |
| L2 支撑图 | 技术栈标签云、鉴权链路 | SVG 或生图，二选一 |
| L3 母版徽标 | 全篇统一角标（项目 Logo 字样） | SVG，固定 C 区左侧 |

**生图约束**：所有 L1 统一视觉类型（科技蓝抽象概念插画/3D 渲染），禁止摄影/插画/3D 混用；产物存 `assets/`，英文短名。
